# 🤖 Crynova AI

المساعد الذكي الرسمي لمنصة Crynova.

يساعد المستخدمين في فهم المنصة، الخدمات، الإحالات،
المكافآت، المشاكل، وطريقة استعمال النظام.

---

## 🚀 المميزات

- 🤖 محادثة ذكية مع المستخدمين
- 🇩🇿 الرد بالدارجة الجزائرية
- 🧠 ذاكرة قصيرة للمحادثة
- 📚 قاعدة معرفة خاصة بـ Crynova
- 🔄 إعادة محاولة تلقائية عند فشل Gemini
- ⏱️ Timeout لحماية البوت من التعليق
- 🛡️ نظام Moderation
- 🔗 كشف الروابط الخارجية
- 🚫 حذف الإهانات المحددة
- 💬 الحفاظ على الشكاوى وعدم حذفها تلقائيًا
- 🔐 عدم طلب كلمات السر أو رموز التحقق
- ⚙️ إعدادات Environment Variables
- ☁️ قابل للتشغيل على Render
